# YFE Workshop 2.0 — Learning & Projects

This repository documents my learning journey through YFE Workshop 2.0, a 12-week programme covering Computer-Aided Design (CAD) and Embedded Systems.

I'm using this repository to document practical exercises, projects, technical notes and lessons learned throughout the programme.

Learning Tracks

1. Computer-Aided Design (CAD)
Working with Autodesk Fusion 360 to explore:
 2D drafting and technical drawings
 3D modelling
 Assembly design
 Mechanical design principles

2. Embedded Systems
Learning and practising concepts involving:
 ESP32 architecture and GPIO
 Sensors and peripheral interfacing
 ADC, PWM, timers and interrupts
 Communication protocols
 Firmware development and debugging
 STM32 and embedded system integration
